# 九格经营演示包

## 启动

在当前目录执行：

```bash
node server.mjs
```

演示入口：

```text
http://127.0.0.1:8000/?demo=1
```

普通用户入口：

```text
http://127.0.0.1:8000/
```

## 交给视频模型

提供整个文件夹，并要求模型先读取 `DEMO_VIDEO_SCRIPT.md`。录制时使用演示入口，不修改预填数据；最后一个镜头使用 `demo-assets` 内的真实甘特图预览。

## 演示结果

- 虚构品牌：拾味蛋糕
- 九宫格定位：区域首选
- 默认计划：2026 年 10 月
- 首要经营问题：新客和进店客流不足
- 主攻引擎：产品与利润、拉新获客
- 本月核心：5 项
- 完整任务：47 项
