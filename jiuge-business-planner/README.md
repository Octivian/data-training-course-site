# 九格经营

面向蛋糕品牌经营者的月度经营规划 H5。产品从品牌诊断开始，经由经营九宫格和六套经营引擎完成策略取舍，最终生成带日期、验收口径和甘特图的月度经营工作计划。

## 当前流程

```text
经营诊断 -> 九宫格定位 -> 六引擎取舍 -> 月度计划 -> 甘特图 Excel
```

## 本地运行

```bash
node server.mjs
```

普通入口：

```text
http://127.0.0.1:8000/
```

虚构案例演示入口：

```text
http://127.0.0.1:8000/?demo=1
```

默认端口为 `8000`，可通过 `CAKE_PLANNER_PORT` 修改。

## 运行依赖说明

前端页面使用原生 HTML、CSS 和 JavaScript。甘特图导出接口依赖 `@oai/artifact-tool`，目前使用 Codex 工作区提供的运行环境；普通 Node 环境未安装该依赖时，页面仍可浏览，但 Excel 导出接口无法运行。正式部署前需要将导出层迁移到可公开安装的表格依赖或独立服务。
